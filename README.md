# РИТМ — Telegram Mini App

Официальный Telegram Mini App для сервиса **«РИТМ»** (*«Отмены, расписание и перекличка работают сами»*), воссозданный пиксель-в-пиксель на основе оригинального дизайн-макета.

---

## 1. Стек технологий
- **Фреймворк:** React 18 + TypeScript + Vite
- **Стилизация:** Tailwind CSS + CSS-переменные дизайн-системы РИТМ
- **Шрифты:** `Unbounded` (акцентный/логотип) + `Inter` (интерфейсный)
- **Иконки:** `lucide-react` (векторные SVG)
- **Telegram SDK:** `telegram-web-app.js` (интеграция HapticFeedback, BackButton, MainButton, themeParams, initDataUnsafe.user)

## 3. Быстрый запуск

### Вариант A. Мгновенный запуск без установки Node/npm (Standalone)
Просто откройте файл `mini-app/standalone.html` или `site/app.html` в любом браузере:
```powershell
# В PowerShell:
Start-Process "d:\Проект тг\mini-app\standalone.html"
```
Или запустите локальный сервер через встроенный Python:
```powershell
python -m http.server 3000 --directory "d:\Проект тг\mini-app"
```
Перейдите на `http://localhost:3000/standalone.html`.

### Вариант B. Продакшен запуск через Node.js и Vite
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
3. Соберите проект для продакшена:
   ```bash
   npm run build
   ```
   Собранные файлы будут помещены в папку `dist/`.

## 4. Инструкция по деплою (нужен HTTPS)

Telegram Mini Apps требуют протокол **HTTPS**.

### Деплой на Vercel (Рекомендуется, 1 минута):
1. Установите Vercel CLI: `npm i -g vercel` (или подключите репозиторий через vercel.com).
2. Выполните:
   ```bash
   cd "d:\Проект тг\mini-app"
   vercel
   ```
3. Получите готовый HTTPS URL: `https://ritm-app.vercel.app`.

### Деплой на GitHub Pages:
Файл `d:\Проект тг\site\app.html` уже скопирован в папку сайта. Если включен GitHub Pages:
URL приложения: `https://<ваш-логин>.github.io/<имя-репозитория>/app.html`.

## 5. Подключение к боту в Telegram через @BotFather

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newapp`.
3. Выберите вашего бота (например, `@ritm_study_bot`).
4. Введите название приложения: `РИТМ`.
5. Введите описание: `Отмены, расписание и перекличка работают сами`.
6. Загрузите иконку (640×640 px) или GIF (по желанию).
7. Укажите ваш HTTPS URL: `https://ваш-домен.vercel.app/` (или прямую ссылку на `app.html`).
8. Введите короткое имя (short name): `app`.
9. Готово! Ссылка на приложение: `t.me/<ваш_бот>/app`.

Также можно сделать кнопку меню:
1. В `@BotFather` отправьте команду `/setmenubutton`.
2. Выберите бота.
3. Отправьте URL приложения и текст кнопки (например, `Открыть РИТМ ⚡`).

## 6. Список мест, где результат может отличаться от скриншота

1. **Интерактивность:** на статичном скриншоте кнопки не нажимаются. В приложении добавлены живые состояния, выбор собственного статуса в перекличке с динамическим пересчетом явки, всплывающие окна и звуковой/тактильный отклик Telegram HapticFeedback.
2. **Шрифт логотипа:** на скриншоте использован закрытый геометрический шрифт с наклоном. В проекте подключен открытый вариативный геометрический шрифт `Unbounded` из Google Fonts с начертанием `font-black`, максимально близкий по пропорциям и глифам.
3. **Реальный экспорт:** кнопка `/export → .xlsx` на макете статична; в коде она генерирует настоящий структурированный файл таблицы Excel (.csv в кодировке UTF-8 с BOM) и позволяет скопировать готовый текстовый дайджест в один клик.
4. **Дополнительные экраны:** реализовано полноценное переключение табов (Расписание недели, Статистика группы, Настройки) вместо пустых заглушек.
